# WP-13 : Espace « Analyse » (interface)

- Statut : terminé (2026-11-27), branche `worktree-agent-ac52f7ff019f58037`.
- Spécification : `docs/specs/increment-1.md`, section 7 (WP-13) ; maquette `docs/maquettes/increment-1/Analyse.dc.html`. ADR 0021 ; nouvelles questions ouvertes [PO-110] à [PO-114]. Capture pour le PO : `docs/wp/WP-13-analyse.png`.

## Ce qui a été fait

Page `/missions/[id]/analyse` (composant `components/analysis-page.tsx`, sous-composants dans `components/analysis/`) :

- **Description et « Analyser »** : éditeur partagé (WP-10), bouton « Analyser » (désactivé pendant une analyse), jauge de progression (`run.progress`, avec repli par `GET runs/:runId`), toast de fin (version produite) ou d'échec, message dédié pour 409 `ANALYSIS_IN_PROGRESS` et pour une description vide. Avant de figer la description, le texte est enregistré tout de suite côté serveur (ADR 0021).
- **Sources** : liste (description par révision, documents), état de lecture en texte, nombre d'éléments qui citent chaque source (calculé sur le modèle), dépôt multipart (plusieurs fichiers), « Analyser ce document », « Voir le texte », encadré de **contradiction** (écarts ouverts, deux versions) avec lien vers l'onglet Écarts.
- **Onglets** Métier, Acteurs, Activités, Données, Flux, Règles, Indicateurs, Écarts (avec effectifs) : liste triée par code, filtre de statut, **badge de statut** (icône et texte, jamais la couleur seule), **fiche** (nature, code, attributs propres au type, origine, confiance, justification, citations ; deux versions et leurs citations pour un écart ; identifiant et versions en mode expert, [PO-112]). **Complétude par concept** (score, jauge, liste des manques) via `completeness()` du modèle.
- **Visionneuse** (dialogue) : morceau cité avec le passage surligné (`<mark>` souligné), morceaux voisins ; l'ordinal est retrouvé par le `chunkId` de la référence.
- **Historique** : versions (cause, date, « par vous »), changements d'une version (ajoutés, modifiés, retirés avec libellés), **retour arrière** avec confirmation (crée une nouvelle version), réservé aux profils pouvant éditer.
- **Temps réel** : le modèle vient de `useMissionModel()` (un second consultant voit la version sans recharger) ; la vue consultée (« Analyse, Acteurs, … ») est publiée dans la présence (`setView`, `usePublishView`).
- **Tableau de bord** : les éléments « À faire » deviennent des liens vers l'espace Analyse (hypothèses, questions, contradictions) [PO-113].
- Validateur : la page n'affiche qu'un avis (aucun accès aux sources, PO-73).
- Autres : `apiRequest` accepte un `FormData` ; endpoints d'analyse, sources, versions ; `errors.ANALYSIS_IN_PROGRESS` ; textes `analysis.*` dans `fr.json`.
- **Serveur de coédition** : message sans état `workspace.flush` / `workspace.flushed` (ADR 0021), test d'intégration.
- **Correctif WP-11** : `GET sources` renvoyait `chunkCount = 0` pour toutes les sources (la colonne était mal corrélée dans la sous-requête) ; corrigé et couvert.
- **E2E** : worker pg-boss lancé par `e2e/global-setup.ts`, `e2e/test-env.ts` partagé, `e2e` dépend de `@processia/test-fixtures`.

## Écarts et choix

1. **Questions et hypothèses** : les panneaux « Questions de l'outil » et « Hypothèses à examiner » de la maquette sont à WP-14 ; ici, les hypothèses se repèrent par badge et filtre de statut [PO-110]. Les boutons « Voir les 4 livrables » et « Soumettre au validateur » relèvent de WP-15/16.
2. **Pas de confirmation d'élément ni de résolution d'écart** dans cet écran [PO-110].
3. **Ancre `#questions`** du tableau de bord sans cible avant WP-14 [PO-113].
4. Réponses de l'API typées par `z.custom<T>()` (les contrats n'ont pas de schémas zod pour les DTO de sources et de versions).
5. Pas de nom d'auteur dans l'historique (seul « par vous » est affiché) : l'API ne renvoie que l'identifiant.

## Dettes

- Page à une colonne sur mobile non testée visuellement au-delà de la mise en page fluide.
- Pas de pagination de la liste d'éléments (défilement interne) ni de recherche.
- Le téléchargement du document d'origine (`download-url`) n'est pas proposé.
