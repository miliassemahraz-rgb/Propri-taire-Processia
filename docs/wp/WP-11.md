## Ce qui a été fait

`packages/ingest` (`exceljs`, `file-type`, `mammoth`, `unpdf`) :

- `detectFile` : type par signature, extension cohérente, 50 Mo, texte UTF-8 sans octet nul.
- `extractDocumentText` : PDF (une page par bloc ; moins de 20 caractères par page en moyenne = scan, `needs_vision`), DOCX (titres et paragraphes numérotés, titre courant), XLSX (une ligne par bloc, valeurs nommées par l'en-tête, plage de cellules), TXT/MD (paragraphes localisés par lignes), image (`needs_vision`).
- `chunkBlocks` : morceaux d'environ 6 000 jetons (24 000 caractères), jamais à cheval sur deux feuilles, localisateur couvrant l'étendue regroupée ; `blocksFromPages` (transcription visuelle), `blocksFromParagraphs` (textes libres).

`packages/ai` : pipeline `extraction.document_visual` (schéma par page, prompt `extraction.document_visual.fr.md`, pièce jointe PDF ou image). Son scénario factice du pilote reste à WP-12.

`packages/test-fixtures` : générateurs déterministes `buildPdf`, `buildScannedPdf`, `buildDocx`, `buildXlsx`, `buildPng` (jeux de test PDF, DOCX, XLSX, image).

`packages/contracts` : DTO et schémas des sources (`SourceDto`, `ChunkDto`, `ChunkViewDto`, `RunProgressMessage`, canal `mission_messages`), codes d'erreur `FILE_TOO_LARGE` (413) et `UNSUPPORTED_FILE_TYPE` (415).

`apps/api` :

- `StorageModule` (`StorageService` : put, get, delete, URL présignée 5 minutes ; clés `missions/<id>/sources/<id>/<nom>`).
- `JobsModule` (`JobsService` : pg-boss, démarrage paresseux, `addConsumer`, `startConsuming`) ; `worker.ts` démarre un contexte Nest et consomme les files.
- `SourcesModule` : `SourcesService` (dépôt, `createTextSource`, `freezeDescription`, liste, détail, morceaux, visionneuse, URL présignée, progression), `IngestService` (tâche `ingest.document`), `SourcesController` ; `AiProviderRegistry.supportsDocuments`.
- Routes sous `/missions/:missionId` : `POST sources/documents` (`model.edit`, multipart `file`), `POST sources/description` (`model.edit`, fige la description Yjs), `GET sources`, `GET sources/:id`, `GET sources/:id/chunks`, `GET sources/:id/chunks/:ordinal?charStart&charEnd` (visionneuse), `GET sources/:id/download-url`, `GET runs/:runId` (`mission.read_workspace`).
- Progression : chaque étape met à jour `analysis_runs` (kind `ingest`) et émet `run.progress` sur `pg_notify('mission_messages')`.
- ADR 0016 ; RUNBOOK (section worker) ; [PO-70] à [PO-73].

## Écarts et choix

1. **Pas d'URL ni de lecture pour le validateur** : [PO-73]. Les sources sont lisibles sous `mission.read_workspace`.
2. **Capacité `documents`** : lue dans la configuration IA active du client (`supportsDocuments`), pas dans le fournisseur factice (qui l'a toujours) ; sans configuration, le client n'en dispose pas [PO-70].
3. **`pgboss` créé avec le rôle propriétaire** (ADR 0016) : le rôle applicatif ne peut pas créer de schéma.
4. **Route `GET runs/:runId`** ajoutée (lecture de la progression sans WebSocket). WP-12 pourra la généraliser aux autres exécutions (`analysis_runs`).
5. **Le lien source vers exécution** n'est pas stocké (`analysis_runs` n'a pas de `source_id`) : la réponse du dépôt donne `runId` et le message `run.progress` porte `sourceId`. Une colonne serait une migration, laissée à WP-12 si besoin.
6. **Pas d'extraction des positions de caractères des PDF** (« page et positions ») : le localisateur est la plage de pages ; les positions de caractères (`charStart`, `charEnd`) se calculent dans le texte du morceau (spécification 4.5), ce que fournit la visionneuse.
7. **Anciens formats `.doc` et `.xls`, ODT, CSV, WebP** : refusés [PO-72].

## Dettes

- Le fichier est tenu en mémoire (multer, puis S3, puis extraction) : correct à 50 Mo, à reprendre en flux si la limite monte.
- Pas de suppression d'un objet S3 ni d'une source (purge de mission : WP-25).
- DOCX : les tableaux sont lus cellule par cellule comme des paragraphes (pas de structure en lignes).
- La transcription visuelle envoie le document entier en une requête : pas de découpage des longs scans.
- Le journal `ai_calls` de l'extraction visuelle ne conserve pas la pièce jointe (métadonnées seulement, WP-09).
