## Écarts par rapport à la spécification

1. **Migrations dans `src/migrations/`** et non `packages/model/migrations/` : `tsc` a `rootDir: src`.
2. **Catalogue dans `src/catalog/`** (conforme à la fiche WP-02, pas à la section 2.6 qui écrit `catalog/`). Importé avec `with { type: 'json' }`.
3. **Ids de ChangeSet** : `ElementIdSchema` accepte un UUID v7 **ou** `tmp:n` partout (références comprises), pour que `ModelOp.add` puisse porter des éléments à ids temporaires. Les clés de `BusinessModel.elements` sont des UUID v7 stricts et doivent égaler `element.id` (contrôle zod seulement, absent du JSON Schema). Un `tmp:n` dans une référence d'un modèle persisté n'est pas détecté : à résoudre et vérifier par `applyChangeSet` (WP-03).
4. **Types récursifs écrits à la main** : `ModelOp` et `ChangeSet` sont des types TypeScript explicites (les schémas sont annotés `z.ZodType<…>`), car `Element` contient `Optimisation` qui contient un `ChangeSet` ; l'inférence est circulaire sinon.
5. **JSON Schema** : zod ne peut pas exporter ses `refine`. Les règles croisées sont réécrites en `if`/`then` dans `src/json-schema.ts` ; la parité est testée par le jeu commun. Draft-07 (ajv par défaut), pas 2020-12. Seul `BusinessModel` est exporté ; `ValidationSubmission` n'a pas de JSON Schema (non demandé).
6. **Règles ajoutées** à la spécification (déductions de commentaires du texte) : événement de bordure → `attachedToId`, écart résolu → `resolution`, `hypothesis` → `rationale`. Voir [PO-25] (valeur par défaut appliquée).
7. Pas de dépendance `uuid` : générateur UUID v7 de 15 lignes, pur, plutôt qu'une dépendance qui lit l'horloge.
8. Les signatures de `composeToBe`, `applyChangeSet`, etc. (spécification 2.5) ne sont pas déclarées : elles relèvent de WP-03.

## Dettes

- Pas de JSON Schema pour `ChangeSet` autonome ni `ValidationSubmission` (seront utiles à WP-09 pour les sorties de pipelines IA ; `ChangeSet` est déjà dans `definitions` du schéma du modèle).
- `confidence`, `severity`, etc. : bornes seulement ; aucune cohérence inter-éléments (références vers des ids existants) : c'est le rôle de WP-03.
