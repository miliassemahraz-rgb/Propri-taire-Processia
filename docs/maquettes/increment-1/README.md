| Fichier                 | Écran                                                                                                  |

| `Cartographie.dc.html`  | Cartographie : niveaux, vue simplifiée / BPMN, modification par dialogue avec aperçu et retour arrière |

| `Validation.dc.html`    | Portail du validateur : décisions par optimisation, dépendances, refus en cascade, clôture             |
